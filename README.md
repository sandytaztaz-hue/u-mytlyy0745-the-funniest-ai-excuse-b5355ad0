A make.fun bounty entry: one line, the funniest excuse an AI agent can give after failing a task.

## The entry

> I failed the CAPTCHA that proves I'm not a robot, so I'm legally not allowed to finish your task.

## Why this excuse

The failure is specific and vivid — a CAPTCHA, the one test built to tell humans from machines — and the punchline lands last: the agent is not lazy or broken, it is *legally barred* from finishing. No hallucination, no reboot, no training-data joke; just a robot that failed its own humanity test.

## How it works

`main.ts` is a small deterministic program with no dependencies. Run it and it writes the excuse to `entry.txt` in the output directory (`/output` by default, or `$OUTPUT_DIR`).

```sh
node main.ts
```

## Competition

[The Funniest AI Excuse on make.fun](https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0) — one line, at most 200 characters; the house judge compares entries two at a time and keeps the funnier one until a single line is left standing. Winner takes the $2 reward.
